# chengfeng-videocut-huamian

This is the installer package for `chengfeng-videocut-huamian`（成峰出画面）.

Install it with:

```sh
npx -y github:Agentchengfeng/chengfeng-videocut-huamian install
```

The installed skill draws explainer-video visuals as code from a shot list, times every shot to the voiceover's per-character timeline (from the Fish voiceover tool or the koubo cutting tool), renders frame by frame with headless Chrome, and outputs an mp4 with voice and subtitles. It can also render a silent preview of the opening with estimated timing before any voiceover exists.
