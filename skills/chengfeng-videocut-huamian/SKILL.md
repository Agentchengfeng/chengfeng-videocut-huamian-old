# 出画面

画面是代码画的：一个网页，给它一个时刻 T（秒），它就把那一帧摆出来；脚本一帧一帧截图，接成 mp4。所以能从任何一秒开始出、只出一段，改一镜只重出那一段。

一条片子一个**画面目录**（比如 `<片名>-画面/`），里面：`index.html`、`引擎.js`（一般不改）、`镜头.json`（每镜念什么、画什么）、`data.js`（对时算出来的时间）、`镜头.js`（每镜的画面代码）、`素材/`（截图、录屏）。脚本都在本 skill 的 `scripts/` 里，下面写 `S=<本 skill 目录>/scripts`。

```text
1 建目录     拷模板                              cp -R
2 镜头表     分镜稿 → 镜头.json                  你写
3 对时       配音里每个字的时间 → data.js          对时.py
4 写画面     一镜一段 → 镜头.js                   你写，照 references/画面规矩.md
5 边做边看   截几张、拼一张总览                   出片.cjs … 截
6 出片       一段或整片 → mp4（带口播）            出片.cjs
7 检查       空屏、一帧闪、卡一帧、总览图          检查.py
```

**每一步的完成判据是它的产出文件**；出片和检查的“问题”要是“无”，或者每条都说清楚为什么不改。

## 0. 准备

- Node.js 18 以上、`python3`、`ffmpeg` / `ffprobe`（macOS：`brew install node ffmpeg`）。
- 一个 Chrome 系浏览器：本机装的 Google Chrome、Edge、Chromium 都行，脚本自己找；装在别处就设环境变量 `CHROME_PATH`。
- `playwright-core`（开浏览器截图用）：安装器已经装进 `~/.chengfeng-videocut-huamian/`；没有就 `npm install --prefix ~/.chengfeng-videocut-huamian playwright-core`。
- 缺什么告诉用户怎么装，不替用户装。

## 1. 建目录

```sh
cp -R <本 skill 目录>/assets/模板 <片名>-画面
```

模板里是一条能直接跑的示例片（《迪士尼动画十二法则》开头三镜，没有声音），第一次用先跑一遍，确认环境没问题：

```sh
python3 $S/对时.py <片名>-画面 <片名>-画面/时间线-示例.json
node $S/出片.cjs <片名>-画面 0 end <片名>-画面/示例.mp4
```

跑通以后，把示例的 `镜头.json`、`镜头.js`、`时间线-示例.json`、`data.js`、`示例.mp4` 换成这条片子自己的。

## 2. 镜头表：镜头.json

照分镜稿一镜一条：

```json
{
 "宽": 1080, "高": 1440, "fps": 25, "字幕": true,
 "镜": [
  {"n": 1, "口播": "这一镜要念的原话", "画面": "分镜稿里这一镜画什么"},
  {"n": 2, "口播": "…", "画面": "…"}
 ]
}
```

- `口播` 照口播稿原话抄，一字不改；各镜的口播按顺序接起来，就是整条口播稿。每一镜都要有要念的字。
- 尺寸：竖版 1080×1440（3:4）或 1080×1920（9:16），横版 1920×1080。用户没说就问一句。
- `画面` 是给你自己写代码时看的，可以写长。别的字段（素材文件名等）随便加，会原样带进 data.js。

## 3. 对时

```sh
# Fish 配音工具配的
python3 $S/对时.py <画面目录> <配音目录>/时间线.json --口播 <配音目录>/口播.wav
# 自己录、用剪口播剪的（要跑完剪口播的核对那步）
python3 $S/对时.py <画面目录> <剪口播目录> --口播 <剪口播目录>/剪后.wav
# 还没配音：按估的语速先出无声预览
python3 $S/对时.py <画面目录> --估 310
```

- 每一镜从它第一个字开口前 0.08 秒开始，镜和镜之间不留缝；不到 1 秒的镜往前借时间。
- 报“对不上”：镜头.json 的口播和配音念的不是同一版。先照实际念的改口播，再跑；真要照写加 `--force`。
- 改了口播、重配了音，重跑这一步就行：画面里写的都是“念到哪个词”，时间跟着走，不用改 镜头.js。

## 4. 写画面：镜头.js

**先读 [references/画面规矩.md](references/画面规矩.md)。** 一镜一段：

```js
画面[3] = (t, T, 镜) => {               // t 这一镜里的秒，T 全片的秒
  const e = 建(层(3), `<div data-k="题" style="font-size:96px">十二法则</div>`);   // 第一次调用才建元素
  摆(e.题, { x: W / 2, y: 600, s: lerp(.8, 1, 进度(T, at(3, '十二'))), o: 进度(T, at(3, '十二'), .3) });
};
```

| 用得上的 | 是什么 |
|---|---|
| `at(n, '词', 第几次, 偏)` | 第 n 镜口播里这个词开始念的秒（全片时间）。找不到会记成问题 |
| `念完(n, '词')` | 这个词念完的秒 |
| `进度(T, 起, 长, 曲线)` | 从“起”开始、“长”秒内从 0 走到 1 |
| `缓.出 / 进 / 进出 / 弹 / 直` | 缓动曲线：出现用“出”，离开用“进”，推拉镜头用“进出”，大字砸下用“弹” |
| `层(n)` | 第 n 镜的图层；这一帧谁调了谁显示，没调的自动藏起来 |
| `建(层, html)` | 第一次把 html 放进图层，返回 `data-k` 名字 → 元素 |
| `摆(元素, {x, y, s, sx, sy, r, o})` | 中心放在 (x, y)，缩放、旋转（度）、不透明度 |
| `clamp`、`lerp`、`W`、`H`、`镜(n)` | 夹住、插值、画面宽高、某一镜的数据 |
| `预载('素材/a.png', …)` | 图片先加载完再出片，写在 镜头.js 顶上 |
| `画面.底 = T => {}`、`画面.顶 = T => {}` | 每一帧都画：铺底、跨镜的东西 |

- 换镜要过渡：在下一镜开头几帧里也调上一镜的函数（`画面[2](T - 镜(2).a, T, 镜(2))`），把它淡掉或推走。
- 截图、录屏放 `素材/`，用相对路径。录屏视频先用 ffmpeg 抽成图片序列，按 T 换图。
- 字体、背景色在 index.html 的 `#台` 里改；字幕样式改 `#字幕`，不要字幕在 镜头.json 写 `"字幕": false`。

## 5. 边做边看

```sh
node $S/出片.cjs <画面目录> 截 <画面目录>/看 每 2.5          # 每 2.5 秒一张，外加一张 总览.jpg
node $S/出片.cjs <画面目录> 截 <画面目录>/看 12.3 12.8 13.4   # 指定几秒
node $S/出片.cjs <画面目录> 截 <画面目录>/看 每 2.5 --两次    # 顺便查同一秒截两次一不一样
```

- 写完一两镜就截那几秒看，别等整片。看 `总览.jpg` 对着画面规矩逐条查。
- 判一段“空”“没动”之前，至少每秒截一张：隔几秒截一张会正好落在转场空档上。
- “问题”里有“截两次不一样”，就是画面里有东西没按 T 算，先修。

## 先出开头看画风（还没配音时）

用户要先看画风、看开头：`--估` 对时，只写前几镜，出前 30 秒给用户看：

```sh
python3 $S/对时.py <画面目录> --估 310
node $S/出片.cjs <画面目录> 0 30 <画面目录>/开头预览.mp4
```

要比几种画风，就拷几份画面目录，各写各的开头，一起给用户挑。定了再写全片；配好音以后重跑第 3 步，时间换成真的。

## 6. 出片

```sh
node $S/出片.cjs <画面目录> 40 55 <画面目录>/段.mp4 --口播 <口播.wav>     # 一段
node $S/出片.cjs <画面目录> 0 end <成片.mp4> --口播 <口播.wav>            # 整片，片尾定格 1 秒
```

- 最后打印的“问题”要是“无”。有就照着改：页面报错、口播里找不到的词、字体没装、还没写画面的镜。
- 慢的话加 `--路 6`（几个页面一起截，一般不超过 CPU 核数的一半）。
- 只改了一镜：先出那一段看，确认了再出整片。

## 7. 检查

```sh
python3 $S/检查.py <成片.mp4> --数据 <画面目录>/data.js
```

列出空屏、一帧闪、卡一帧，出一张 `<成片名>-总览.jpg`。机器挑出来的只是“要看一眼”的地方：逐个截那一秒看，是真问题就改，不是就在交付时说明。

## 交付

给用户：成片 mp4、总览图、检查结果。报告写：几镜、多长、对时用的哪份配音、检查里每一条怎么处理的、哪些素材是占位的（规矩 7）、哪些地方没人看过。这是不带配乐、音效的基础片。
